🔢 Calculateur de systèmes de numération

Structure Machine 1 · conversions, arithmétique binaire, compléments, codes, IEEE 754 et algèbre de Boole

Résoudre (chiffres)b = valeur en base 10.

  • Base b → décimal : somme de chiffre × brang (puissances négatives après la virgule).
  • Décimal → base b : partie entière : divisions successives par b, lire les restes de bas en haut. Partie fractionnaire : multiplications successives par b, lire les parties entières de haut en bas.
  • 2 ↔ 8 ↔ 16 : regrouper les bits par 3 (octal) ou par 4 (hexadécimal) à partir de la virgule, en complétant par des 0.
  • Addition binaire : 0+0=0, 0+1=1, 1+1=10 (retenue 1), 1+1+1=11. Soustraction : avec emprunt, ou addition du complément à 2. Multiplication : décalages et additions. Division : décalages et soustractions.
  • Nombres négatifs : signe-valeur absolue (bit de poids fort = signe) ; complément à 1 (inverser les bits) ; complément à 2 (inverser puis +1). Intervalle en C2 : −2n−1 … 2n−1−1. A−B = A + C2(B) ; dépassement de capacité quand deux opérandes de même signe donnent un résultat de signe opposé ; la retenue finale est ignorée.
  • Base inconnue : écrire le polynôme en b, puis résoudre l'équation.
  • Codes : BCD 8421 chiffre par chiffre ; Excess-3 = BCD de (chiffre+3) ; Gray : gn=bn, gi=bi⊕bi+1 ; inverse : bn=gn, bi=bi+1⊕gi. ASCII sur 7 bits : '0'=48, 'A'=65, 'a'=97.
  • IEEE 754 : 32 bits = 1 signe + 8 exposant (biais 127) + 23 mantisse ; 64 bits = 1 + 11 (biais 1023) + 52. Valeur = (−1)s × 1,m × 2E−biais. Étapes : signe → |x| en binaire → normalisation → E = e + biais → mantisse.
  • Algèbre de Boole : A+A'=1, A.A'=0, A+AB=A, A+A'B=A+B ; De Morgan : (AB)'=A'+B', (A+B)'=A'B'. Simplifier algébriquement, avec une table de Karnaugh (regrouper des 1 adjacents par 2, 4, 8, en ordre de Gray) ou par Quine–McCluskey.
  • Additionneurs : demi-additionneur S=A⊕B, R=A.B ; additionneur complet S=A⊕B⊕Cin, Cout=AB+Cin(A⊕B).
